# 📊 Observability & Monitoring

## Overview

This area contains monitoring and observability projects for metrics, logs, traces, dashboards, alerting, and production troubleshooting.

## Scope

- Metrics platforms including VictoriaMetrics and Prometheus
- Visualization and alerting with Grafana
- Infrastructure monitoring with Zabbix
- Centralized logging with Elasticsearch, Logstash, Kibana, and related agents
- Distributed tracing and telemetry with OpenTelemetry
- Alert routing, capacity analysis, retention, and operational dashboards

## Project Organization

Future projects in this category will be added as independent subdirectories. Each project will include a dedicated README, sanitized source files, configuration examples, deployment instructions, validation steps, troubleshooting guidance, and operational notes.

## Current Status

The category structure is ready. Projects will be added progressively after their files and documentation have been reviewed and sanitized.
