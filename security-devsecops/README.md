# 🔐 Security & DevSecOps

## Overview

This area covers practical infrastructure security and DevSecOps controls integrated into systems, containers, Kubernetes, and delivery pipelines.

## Scope

- Linux and container hardening
- Image, dependency, configuration, and code scanning
- Identity, authentication, authorization, and access policies
- TLS, certificates, secrets, keys, and trust management
- Kubernetes admission controls and workload-security practices
- Security automation, auditability, and remediation workflows

## Project Organization

Future projects in this category will be added as independent subdirectories. Each project will include a dedicated README, sanitized source files, configuration examples, deployment instructions, validation steps, troubleshooting guidance, and operational notes.

## Current Status

The category structure is ready. Projects will be added progressively after their files and documentation have been reviewed and sanitized.
