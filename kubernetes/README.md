# ☸️ Kubernetes & Container Orchestration

## Overview

This area covers Kubernetes and container-orchestration projects across different distributions, installation methods, networking models, storage systems, and production environments. It is intentionally not limited to RKE2.

## Scope

- Cluster provisioning and lifecycle with kubeadm, Kubespray, RKE2, and other distributions
- Container runtimes and image-management practices
- CNI and network policy with Calico, Cilium, and related technologies
- Ingress, Gateway API, service exposure, and traffic management
- Workload scheduling, autoscaling, disruption, and resource management
- Persistent storage, backup, restore, disaster recovery, and migration
- Security, observability, troubleshooting, and production operations

## Project Organization

Future projects in this category will be added as independent subdirectories. Each project will include a dedicated README, sanitized source files, configuration examples, deployment instructions, validation steps, troubleshooting guidance, and operational notes.

## Current Status

The category structure is ready. Projects will be added progressively after their files and documentation have been reviewed and sanitized.
