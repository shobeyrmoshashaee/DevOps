# 🌐 Infrastructure & Networking

## Overview

This area covers production infrastructure and network engineering, from load balancing and high availability to proxies, routing, DNS, and secure traffic delivery.

## Scope

- High availability with HAProxy, Keepalived, and virtual IPs
- Reverse proxies and traffic management with NGINX and Envoy
- L4 and L7 load-balancing patterns
- IPVS, TCP, UDP, SIP, and source-IP preservation
- DNS, TLS, certificates, routing, VLANs, and firewall considerations
- Connectivity testing, packet analysis, performance, and troubleshooting

## Project Organization

Future projects in this category will be added as independent subdirectories. Each project will include a dedicated README, sanitized source files, configuration examples, deployment instructions, validation steps, troubleshooting guidance, and operational notes.

## Current Status

The category structure is ready. Projects will be added progressively after their files and documentation have been reviewed and sanitized.
