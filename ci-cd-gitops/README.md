# 🚀 CI/CD & GitOps

## Overview

This area contains continuous integration, continuous delivery, GitOps, release engineering, and software-delivery automation projects.

## Scope

- GitLab CI/CD, runners, pipelines, templates, and reusable components
- GitOps workflows with Argo CD, Kustomize, Helm, and environment overlays
- Build, test, packaging, artifact publishing, and container delivery
- Deployment strategies including rolling, blue-green, and canary releases
- Code quality, dependency checks, vulnerability scanning, and policy gates
- Migration, upgrade, rollback, and release-management practices

## Project Organization

Future projects in this category will be added as independent subdirectories. Each project will include a dedicated README, sanitized source files, configuration examples, deployment instructions, validation steps, troubleshooting guidance, and operational notes.

## Current Status

The category structure is ready. Projects will be added progressively after their files and documentation have been reviewed and sanitized.
