## 📐 Repository Standard

Each project added to these categories will have its own directory and documentation covering:

- The problem and production use case
- Architecture and engineering decisions
- Sanitized source code and configuration
- Requirements and deployment instructions
- Validation and troubleshooting procedures
- Security and operational considerations
- Lessons learned and possible improvements

## 🔒 Security and Sanitization

This is a public engineering portfolio. Internal IP addresses, domains, credentials, API tokens, certificates, private keys, kubeconfigs, organization-specific identifiers, and confidential logs must be removed before publication.

See [SECURITY.md](./SECURITY.md) for the complete repository policy.
