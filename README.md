#### 📐 Repository Standard

Each project will be placed inside its relevant knowledge area as an independent directory with:

- Architecture and engineering decisions
- Sanitized source code and configuration
- Requirements and deployment instructions
- Validation and troubleshooting procedures
- Security and operational considerations
- Lessons learned and future improvements

#### 🔒 Security and Sanitization

This is a public engineering portfolio. Internal IP addresses, domains, credentials, tokens, certificates, private keys, kubeconfigs, confidential logs, and organization-specific information must be removed before publication.

See [SECURITY.md](./SECURITY.md) for the complete repository policy.
